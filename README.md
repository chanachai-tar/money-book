# สมุดเงินประจำบ้าน

เว็บแอปจัดการเงินส่วนตัว เปิดบนมือถือแล้วติดตั้งเป็นแอปได้ ข้อมูลทั้งหมดเก็บในเครื่องของคุณ ไม่ส่งขึ้นเซิร์ฟเวอร์ใด

## ทำอะไรได้บ้าง

- **รายรับ–รายจ่าย** จดเร็ว แยกหมวด ค้นหา กรอง แก้ไข และส่งออกเป็น CSV เปิดใน Excel ได้
- **งบรายหมวด** ตั้งเพดานแต่ละหมวด เตือนเมื่อใช้ถึง 80% หรือเกินงบ บอกว่าเหลือใช้ได้วันละเท่าไหร่
- **บิลประจำเดือน** เตือนก่อนครบกำหนด 5 วัน กด "จ่ายแล้ว" แล้วระบบบันทึกเป็นรายจ่ายให้เอง
- **หนี้สิน** คำนวณระยะผ่อนที่เหลือ ลดยอดหนี้อัตโนมัติ (หักดอกเบี้ยก่อน) และดูภาระผ่อนต่อรายได้
- **ทรัพย์สินและเงินสำรองฉุกเฉิน** ดูความมั่งคั่งสุทธิ และเงินฝากพอใช้กี่เดือนถ้าไม่มีรายได้
- **ลดหย่อนภาษีปี 2569** เช็กลิสต์ทุกรายการพร้อมเอกสารที่ต้องเก็บ รวมยอดจากรายจ่ายที่ติดป้ายลดหย่อน และคำนวณภาษีคร่าว ๆ
- **กราฟย้อนหลัง 6 เดือน**
- **อ่านสลิปฟรี** อ่านตัวอักษรในเครื่อง ไม่ต้องสมัครอะไร และไม่มีค่าใช้จ่าย

## เริ่มใช้งาน

### แบบออนไลน์ (แนะนำ) ผ่าน GitHub Pages

1. เปิด repo นี้บน GitHub → **Settings → Pages**
2. ที่ **Build and deployment → Source** เลือก **GitHub Actions**
3. ไปที่แท็บ **Actions** แล้วรอให้ "Deploy to GitHub Pages" เสร็จ (ประมาณ 1 นาที) จะได้ลิงก์รูปแบบ `https://<ชื่อผู้ใช้>.github.io/money-book/`

ทุกครั้งที่ push ขึ้น `main` เว็บจะอัปเดตเอง

> GitHub Pages แบบฟรีใช้ได้กับ repo สาธารณะ ถ้า repo เป็นส่วนตัวต้องใช้ GitHub Pro ขึ้นไป ตัวโค้ดไม่มีข้อมูลการเงินของคุณอยู่ข้างใน การเปิด repo เป็นสาธารณะจึงไม่ทำให้ข้อมูลรั่ว

### ติดตั้งบนมือถือ

- **iPhone (Safari):** เปิดลิงก์ → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**

หลังติดตั้งแล้ว เปิดใช้ได้แม้ไม่มีอินเทอร์เน็ต

### แบบออฟไลน์บนคอมพิวเตอร์

```bash
git clone https://github.com/<ชื่อผู้ใช้>/money-book.git
cd money-book
python3 -m http.server 8000
# เปิด http://localhost:8000
```

## ข้อมูลเก็บที่ไหน

ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์ที่คุณเปิดใช้ แต่ละเครื่อง แต่ละเบราว์เซอร์มีข้อมูลแยกกัน

- **สำรองข้อมูล:** กดปุ่มเฟือง → **ดาวน์โหลดไฟล์สำรอง** ควรทำเดือนละครั้ง
- **ย้ายเครื่อง:** สำรองจากเครื่องเก่า แล้วกด **กู้คืนจากไฟล์** ในเครื่องใหม่
- ถ้าล้างข้อมูลเบราว์เซอร์ (Clear site data) หรือใช้โหมดไม่ระบุตัวตน ข้อมูลจะหาย ให้สำรองไว้เสมอ

ไฟล์สำรองมีข้อมูลการเงินทั้งหมด อย่า commit ขึ้น GitHub (`.gitignore` กันไฟล์ `money-book-backup-*.json` ไว้ให้แล้ว)

## อ่านสลิป (ฟรี)

กด **+** → **อัปโหลดสลิป (ฟรี)** → เลือกรูปสลิปจากอัลบั้ม เลือกได้ครั้งละหลายรูป แล้วตรวจหรือแก้ก่อนกดบันทึก

- ใช้ [Tesseract](https://github.com/naptha/tesseract.js) อ่านตัวอักษรไทยและอังกฤษ**ในเครื่องของคุณเอง** รูปสลิปไม่ถูกส่งไปที่ไหน
- ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อโหลดตัวอ่านภาษาไทยประมาณ 4 MB หลังจากนั้นเบราว์เซอร์เก็บไว้ให้
- อ่านยอดเงิน วันที่ (แปลง พ.ศ. เป็น ค.ศ. ให้) ชื่อผู้รับ และเลขอ้างอิง และกันบันทึกซ้ำจากเลขอ้างอิง
- ใช้ได้ดีกับภาพหน้าจอสลิปจากแอปธนาคาร ใบเสร็จกระดาษหรือรูปเอียง/มืดอาจอ่านพลาด หมวดเดาจากชื่อร้านที่รู้จักเท่านั้น

### ทางเลือก: ใช้ Claude อ่าน (มีค่าใช้จ่าย)

ถ้าอยากให้แม่นขึ้น (อ่านใบเสร็จได้ดีกว่า เดาหมวดและรายการลดหย่อนภาษีให้) ใส่ Anthropic API key ได้ที่ปุ่มเฟือง

1. สร้าง API key ที่ [console.anthropic.com](https://console.anthropic.com) และเติมเครดิต
2. ในแอป กดปุ่มเฟือง → วาง key → **บันทึก key** (กด **ลบ key** เพื่อกลับไปโหมดฟรี)

key เก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ค่าใช้จ่ายคิดตามการใช้งานจริงในบัญชี API ของคุณ อย่าใส่ key บนเครื่องที่คนอื่นใช้ร่วม

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (HTML + CSS + JavaScript ในไฟล์เดียว ไม่ต้อง build) |
| `manifest.webmanifest` | ข้อมูลสำหรับติดตั้งเป็นแอปบนมือถือ |
| `sw.js` | เก็บแคชให้เปิดได้ตอนออฟไลน์ |
| `icons/` | ไอคอนแอป |
| `.github/workflows/pages.yml` | deploy ขึ้น GitHub Pages อัตโนมัติ |

แก้ไขหมวดรายจ่าย ตัวเลขลดหย่อนภาษี หรือสีได้ที่ต้นสคริปต์ใน `index.html` (ค่าคงที่ `OUT_CATS`, `TAX` และตัวแปรสีใน `:root`) ถ้าแก้ `index.html` แล้วมือถือยังแสดงเวอร์ชันเก่า ให้เปลี่ยน `CACHE` ใน `sw.js` เป็นเลขใหม่ เช่น `money-book-v4`

## หมายเหตุเรื่องภาษี

ตัวเลขค่าลดหย่อนอ้างอิงปีภาษี 2569 (ยื่นแบบ ม.ค.–มี.ค. 2570) การคำนวณเป็นแบบคร่าว ๆ สำหรับผู้มีเงินเดือน ก่อนยื่นจริงควรตรวจเงื่อนไขล่าสุดกับกรมสรรพากร แอปนี้ไม่ใช่คำแนะนำทางภาษีหรือการเงิน
